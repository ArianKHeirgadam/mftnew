قالب پیشنهادی فایل PDF

برای تشخیص دقیق مرز هر سؤال، هر سؤال را با «Q1:» یا «سؤال ۱:» شروع کنید. گزینه‌های چهارگزینه‌ای را با A) تا E) بنویسید. پاسخ صحیح اختیاری است؛ اگر در PDF نباشد، پاسخ دانشجو برای تصحیح دستی استاد در صف قرار می‌گیرد.

Q1: پایتخت ایران کدام شهر است؟ A) تبریز B) تهران C) شیراز D) اصفهان ANSWER: B Q2: الگوریتم مرتب‌سازی ادغامی را توضیح دهید. TYPE: ESSAY Q3: موارد سمت راست را به عبارت‌های سمت چپ وصل کنید. TYPE: MATCHING PAIR: Stack => LIFO PAIR: Queue => FIFO PAIR: Tree => Hierarchical structure

برای سؤال وصل‌کردنی از TYPE: MATCHING و برای هر جفت از PAIR: عبارت سمت چپ => پاسخ متناظر استفاده کنید. PDF اسکن‌شده و تصویری در این نسخه OCR نمی‌شود؛ باید متن PDF قابل انتخاب باشد. پس از ورود، سؤال‌ها را در بانک بررسی کنید و سپس آن‌ها را به آزمون اختصاص دهید.
